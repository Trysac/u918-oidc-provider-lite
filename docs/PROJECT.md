# Project record

## Objective

Embeddable OpenID Connect provider for the authorization code flow with mandatory PKCE, rotating refresh tokens, JWKS key rotation and discovery

## Scope

- In scope: the public API documented in [README.md](../README.md), documented and tested.
- Out of scope: anything that needs dependencies or I/O without an accepted ADR.
